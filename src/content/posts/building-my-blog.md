这个博客从一个域名开始：`alice901.xyz`。先把简洁的主页发布出来，再逐步换上 Firefly 的界面，是这次搭建采用的顺序。

## 四个部分，各自负责一件事

| 部分 | 在本站中的作用 |
| --- | --- |
| 域名 | 让读者通过 alice901.xyz 找到这里 |
| GitHub 仓库 | 保存配置、文章和图片 |
| Astro 与 Firefly | 把文章生成有主题样式的网页 |
| GitHub Pages | 托管生成的静态网站 |

源码的地址和读者访问的网站地址，是两个不同的入口。修改仓库中的文件后，还需要构建和发布，网站才会更新。

## 先让最小版本上线

最开始用 Jekyll 和 Minima 做首页、关于页面和第一篇文章。这个阶段的重点是确认整个发布过程能跑通：仓库能部署，域名能解析，HTTPS 能正常使用。

随后迁移到 Astro 和 Firefly，让文章列表、封面、导航和阅读页面更符合自己的习惯。网站依然由 GitHub Pages 托管，域名也沿用原来的设置。

## 写作与发布的日常流程

文章保存在 `src/content/posts/`，使用 Markdown 编写。日常更新可以分成四步：

1. 新建文章，填写标题、日期和摘要。
2. 本地预览，检查正文、图片和链接。
3. 运行正式构建，确认没有错误。
4. 提交到 GitHub，由 Actions 自动发布。

## 给以后留一条回去的路

更换主题前保留备份分支，图片使用清楚的文件名，重要的旧文章地址增加跳转。这些小步骤不会让页面更华丽，却能让之后的维护更从容。

博客搭建完成并不是终点。接下来更重要的事，是继续写下去。
